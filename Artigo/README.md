# Artigo LoRaWAN

O arquivo principal é `artigo_lorawan.tex`. Para gerar o PDF:

```bash
latexmk -pdf artigo_lorawan.tex
```

Para limpar os arquivos auxiliares:

```bash
latexmk -c
```

O texto apresenta a entrega como **projeto técnico**, sem atribuir como
experimentais as metas ainda não validadas em campo. Antes da versão final,
confira a afiliação, o nome do orientador, os limites térmicos e a reconciliação
do orçamento apontada no artigo.
